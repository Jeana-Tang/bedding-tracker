# Bedding Tracker 🧺

管理家里各个房间床单/被罩/枕套的清洗周期，30天一循环，到期前提醒。

## 功能

- **仪表盘**：九宫格卡片，绿色干净/黄色快到期/红色该洗了，点卡片一键标记已洗
- **热力图**：近12周的清洗频率一目了然
- **周期提醒**：每周五飞书推送，列出快到期的床品
- **数据导出导入**：JSON 格式，搬家也不丢

## 使用

1. 直接在浏览器打开 `index.html`
2. 洗了哪件就点哪张卡片
3. 右上角可调整周期天数（默认30天）和提前提醒天数（默认7天）

## 房间与物品

| 房间 | 物品 |
|------|------|
| 主卧 | 床单、被罩、枕套 |
| 哥哥房 | 床单、被罩、枕套 |
| 二宝房 | 床单、被罩、枕套 |

## 数据文件

`data.json` 存放各物品最近一次清洗日期，格式为 `物品ID: YYYY-MM-DD`。日历提醒脚本会读取此文件。
